ml5.js +P5.JS EXAMPLES

This is a collection of examples using ml5.js and p5.js.

Track A 01

BodyPose: keypoints, skeleton lines, and particle visualization.

Track A 02

HandPose: maps finger joint angles and pinch distance to visual variables.

Track A 03

FaceMesh: turns mouth opening and smile strength into an abstract particle system.

Track B 01

BodySegmentation: person matting, background compositing, and export notes.

Track B 02

ImageClassifier: layers classification labels as subtitle-style visual text.

First time opening will request camera permission; if no video, check if browser allows access to camera.
